About This Site

This website demonstrates basic web development and shares simple pointers on appliance energy consumption in Australia.

How it's built

Built with HTML, CSS and JavaScript. The navigation and footer are generated by JavaScript, and styling is handled by an external CSS file.

Data source

Charts are based on the Australian Government's Television Energy Rating dataset, covering screen size, technology, brand, power use and efficiency.
